# Kindle Reading Suite

Позволяет подключить **Яндекс Книги к Kindle** и читать доступные книги своей подписки в KOReader. Также сохраняет статьи на потом, выгружает заметки на компьютер и помогает повторять иностранные слова.

**[Скачать готовый комплект для Mac и Windows](https://github.com/AlexOneTry/kindle-reading-suite/releases/latest)**

## Как начать

1. Скачайте ZIP выпуска и распакуйте его целиком.
2. Откройте **НАЧНИ ЗДЕСЬ.html** — там все инструкции.
3. Запустите **Install-Mac.command** на Mac или **Install-Windows.cmd** на Windows.

Нужны Python 3.9+ на компьютере и уже установленные jailbreak, KUAL и KOReader на Kindle. Установщик проверяет среду устройства; поддержка всех моделей пока не подтверждена. Для MTP предусмотрен ручной перенос.

## Что умеет

- **Книги:** полка и поиск Яндекс Книг, загрузка доступных книг, чтение в KOReader.
- **Статьи:** сохранение страниц сайтов и RSS в EPUB.
- **Заметки:** выгрузка цитат и комментариев в Markdown и JSON по книгам и главам.
- **Языки:** англо-русский словарь, перевод фраз средствами KOReader, карточки слов и экспорт в Anki.
