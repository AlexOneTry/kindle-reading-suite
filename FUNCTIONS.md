# Возможности Kindle Reading Suite 1.0.0

## Установка

- Запуск с Mac и Windows с проверкой Python 3.9+, UTF-8 и русскими путями.
- Поиск USB-дисков по установленному KOReader, выбор при нескольких устройствах, ручной путь.
- Отдельная проверка на Kindle через KUAL: запуск ARMv7-программы, права root, FBInk, размеры экрана, наличие доступного сенсора, сведения о модели и прошивке при наличии.
- Установка Yandex Books после проверки среды. Резервная копия изменённых файлов на компьютере и попытка отката при ошибке записи. Повторная установка пропускает совпадающие файлы.
- Проверка SHA-256 файлов комплекта перед установкой и SHA-512 словаря.
- Подготовка локальных папок для ручного переноса по MTP, включая подключение аккаунта. Прямого автокопирования по MTP нет.

## Yandex Books 0.6.0

- Самостоятельный клиент в KUAL, полка аккаунта, поиск по полке и каталогу сервиса.
- История поиска, карточки с доступными обложкой и аннотацией, книги автора, известные сведения о сериях.
- Сортировка и фильтры, список «Хочу прочитать», загрузки и локальная очередь.
- Загрузка доступного EPUB, офлайн-чтение уже загруженных книг, продолжение последней книги.
- Открытие в KOReader, переход к его закладкам, возврат на полку при выходе из запущенного таким способом KOReader.
- Стабильный путь к EPUB и сохранение соседних .sdr, отдельное подтверждение удаления файла и добавления книги в аккаунт Яндекса.
- Простая встроенная текстовая читалка с локальной позицией. Полноценные шрифты, иллюстрации и выделения доступны в KOReader.
- Заметки и позиция KOReader остаются локальными. Выгрузка позиции обратно в Яндекс не реализована. Информация о сериях может быть неполной.

## Отдельные инструменты KOReader 1.1.0

- Статья по ссылке → EPUB с текстом, заголовками, оглавлением и ссылкой на оригинал. Без изображений и выполнения JavaScript.
- RSS/Atom → несколько EPUB, сохранённые адреса лент, защита от повторного сохранения одной ссылки.
- Сохранение статей на компьютер или непосредственно на USB-диск Kindle.
- Выделения и заметки EPUB из .sdr → JSON, общий Markdown, отдельные конспекты по книгам и главам. Это подборка цитат и комментариев, без автоматического пересказа.
- Время выгрузки с часовым поясом, время заметок как записано устройством, все доступные поля метаданных EPUB и поля документа KOReader.
- Дополнительный англо-русский StarDict FreeDict/WikDict, русский язык перевода фраз при следующем запуске KOReader.
- Vocabulary Builder → HTML-карточки для повторения и TSV для Anki с контекстом, книгой и временем. Переводы только для точных словарных совпадений.
- SQLite читается из локальной копии базы вместе с WAL. Исходная база на Kindle не изменяется.
- Инструкции по встроенным RSS и Wallabag. Конкретная лента или аккаунт Wallabag не подключаются автоматически.

## Ограничения

Не обещается поддержка всех моделей и прошивок Kindle. Комплект не делает jailbreak. Нативный клиент требует ARMv7 с рабочей 32-битной средой и сенсорного экрана. Не поддерживает кнопочное управление старых Kindle и Amazon Fire. Работа недокументированного API Яндекса зависит от сервиса. Windows и новые модели требуют отдельного практического тестирования.
