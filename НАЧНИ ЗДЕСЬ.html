Kindle Reading Suite 1.0.0

Комплект от 4 ноября 2026 года. Yandex Books 0.6.0 остаётся без изменений. Отдельные инструменты KOReader обновлены до 1.1.0. Установщик — 1.0.0.

Что понадобится

- Электронная читалка Kindle с уже работающими jailbreak, KUAL и KOReader. Комплект не выполняет jailbreak, не меняет прошивку и не устанавливает KUAL или сам KOReader.

- Mac или Windows с Python 3.9 или новее. Никаких дополнительных Python-библиотек не требуется.

- USB-кабель с передачей данных. Для новых устройств с MTP есть отдельный порядок переноса.

- Собственный аккаунт и доступ к книгам Яндекса для работы с Yandex Books. Подписка в комплект не входит.

Начало работы

1. Распакуй весь ZIP в обычную папку на компьютере. На Windows сначала нажми «Извлечь всё». Из окна архива запускать файлы нельзя.

2. Выйди из KOReader и подключи Kindle по USB.

3. На Mac открой Install-Mac.command, на Windows — Install-Windows.cmd.

4. Выбери 1. Установщик сам ищет Kindle по установленному KOReader. Если устройств несколько, предложит выбрать одно. При необходимости можно указать путь к диску вручную.

5. Для нового устройства сначала скопируется только проверка совместимости. Извлеки Kindle, открой KUAL → Reading Kit: check compatibility, снова подключи Kindle и запусти установщик, пункт 1.

6. Если проверка среды пройдена, установщик скопирует Yandex Books и дополнение для открытия заметок. После установки на компьютере выбери 4, чтобы подключить свой аккаунт Яндекса. Ввод адреса после входа скрыт.

7. Извлеки Kindle, включи Wi-Fi и открой KUAL → Yandex Books.

Если приложение уже работает и обновление ему не нужно, для статей, заметок и слов используй пункт 3. Пункт 2 устанавливает дополнительный словарь и настройку перевода отдельно.

Проверка среды не является проверкой каждой модели Kindle: касания, возврат из KOReader и открытие книг нужно проверить на конкретной читалке. При неподходящей платформе приложение не устанавливается. Подробности — Инструкции/Совместимость.md.

Если двойной щелчок не запускает программу

Mac. Установи Python для macOS. Открой Terminal, введи /bin/bash с пробелом и перетащи Install-Mac.command в окно, нажми Enter. Для Python с python.org при ошибке сертификатов выполни поставляемую с ним Install Certificates.command из папки Python в Applications. Проверку HTTPS отключать не нужно.

Windows. Установи Python для Windows. В установщике включи добавление Python в PATH и Python Launcher, если эти опции доступны. Открой комплект заново. Программа пробует py -3, затем python. Поддержка Windows зависит также от выбранного выпуска Python; Windows 10/11 — основной целевой вариант. Реальный запуск на Windows в этой сборке ещё не подтверждён.

- Инструкции/Обновление и восстановление.md — резервные копии, обновление и удаление.

Личные книги, заметки, слова, пароли и токены в этот архив не включены. Комплект не является официальным продуктом Amazon, Яндекса или KOReader.

Kindle с подключением MTP

Если Kindle виден как медиаплеер/портативное устройство, но не как обычный диск с путём, автоматический USB-установщик не сможет писать на него. В macOS может понадобиться MTP-клиент, например OpenMTP. В Windows копирование обычно доступно в Проводнике во внутреннюю память устройства.

Прямое автоматическое копирование по MTP в этом выпуске не реализовано. Можно подготовить файлы на компьютере и перенести вручную. Выполняй команды из распакованной папки Suite. На Windows вместо python3 используй py -3 или python.

Сначала проверка

python3 installer.py stage --output "MTP-Check"

Скопируй папку extensions из MTP-Check в корень внутренней памяти Kindle, где уже есть koreader. Извлеки устройство и запусти KUAL → Reading Kit: check compatibility.

Подключи снова и скопируй extensions/reading-kit-check/report.json с Kindle в папку Suite на компьютере. Не используй отчёт с другого устройства.

Затем приложение

python3 installer.py stage --report "report.json" --output "MTP-Ready"

Если среда подходит, в MTP-Ready появятся extensions и koreader. Перед заменой существующих файлов сохрани их копию с Kindle на компьютер. Резервная копия установщика в этом режиме относится только к локальной папке MTP-Ready; копированием на Kindle управляет MTP-клиент.

Для первого входа подготовь файл подключения:

python3 installer.py connect "MTP-Ready"

После входа скопируй extensions и koreader из MTP-Ready в корень Kindle с объединением папок. Не удаляй и не заменяй целиком существующую папку koreader. После переноса удали локальный MTP-Ready/extensions/yandex-books-pw2/pairing.txt, он содержит данные входа. Извлеки Kindle и открой KUAL → Yandex Books.

Статьи, заметки и слова по MTP

Статьи сначала сохраняй на компьютер и переноси EPUB через Проводник/MTP-клиент. Для заметок скопируй выбранные EPUB вместе с соседними папками .sdr в локальную папку, затем выполни:

python3 Reading-Tools/reading.py notes "Local-Books"

Для слов создай локальную папку Local-Kindle/koreader/settings, скопируй туда vocabulary_builder.sqlite3 и файл с суффиксом -wal, если он есть. Также скопируй koreader/reader.lua, чтобы утилита распознала структуру. Затем:

python3 Reading-Tools/reading.py words "Local-Kindle"

Копируй базу только после выхода из KOReader. Сам Python-код не обращается к виртуальным MTP-путям.

Как пользоваться

Яндекс Книги

Открой KUAL → Yandex Books. Интернет нужен для обновления полки, поиска и первой загрузки книги. Книга должна быть доступна твоему аккаунту. Загруженный EPUB открывается в KOReader без интернета.

В KOReader удерживай слово или протяни выделение по тексту, затем выбери выделение или заметку. Шрифты, оглавление и изображения доступны через обычное меню KOReader. Если книга запущена из Yandex Books, выход из KOReader возвращает на полку. Позиции KOReader и встроенной читалки отдельные и не синхронизируются обратно в Яндекс.

При первом входе открывается официальный экран Яндекса. После входа возможна страница «Авторизация в приложении Букмейт не удалась». Скопируй полный адрес из адресной строки и вставь в окно программы. Ввод скрыт. Ошибка самой страницы не подтверждает вход: программа отдельно проверяет доступ к полке. Не передавай никому адрес с данными входа и файл pairing.txt. Не нужно вводить пароль Яндекса в программу или в чат.

Подробности и полный список возможностей версии 0.6.0 сохранены в папке Yandex-Books, файлы Инструкция.md и Функции.md.

Статьи

Открой пункт 3 основного меню, затем 1. Вставь ссылку на статью. При подключённом USB-диске Kindle можно сохранить EPUB сразу на него. Иначе результат появится в папке пользователя Documents/KOReader/Статьи. На Kindle открой EPUB из папки «Статьи» через файловый менеджер KOReader.

Сохраняются текст, заголовки, ссылки и оглавление. Изображения не переносятся. Сайты с авторизацией, платным доступом, защитой или текстом, который появляется через JavaScript, могут не работать. Ссылки с логином/паролем в адресе отклоняются.

RSS и Wallabag

В меню инструментов пункт 2 принимает RSS или Atom и сохраняет до пяти последних записей. Адрес можно запомнить. Повторное сохранение той же ссылки пропускается. Если сайт не открылся, используется доступный текст из самой ленты; иногда это только анонс.

Для загрузки лент прямо по Wi-Fi открой в KOReader Tools → News downloader и настрой адреса в его Settings. Нажми Download news. Плагин сохраняет HTML. Это отдельный встроенный инструмент KOReader: инструкция.

Для Wallabag нужен свой сервер или аккаунт у поставщика сервиса. В плагине Wallabag на Kindle укажи адрес сервера, имя пользователя, пароль и данные своего API-клиента. Затем обнови список непрочитанных статей. Статьи скачиваются в EPUB. Чужой аккаунт, ключи или сервер в комплекте не предоставляются: инструкция.

Заметки и конспекты

1. Сделай выделения и комментарии в KOReader.

2. Выйди из KOReader, затем подключи USB.

3. В меню инструментов выбери 3. После экспорта программа покажет папку результата.

В Documents/KOReader/Заметки/KOReader-<дата-время> будут общий Markdown, структурированный JSON и папка «Конспекты» с отдельным файлом для каждой книги. В JSON сохраняются все доступные поля метаданных EPUB и документа KOReader, глава, страница, координаты выделения и время, если они есть в исходных данных. Время экспорта содержит часовой пояс компьютера. Время заметки сохраняется в том виде, в котором его записал Kindle: неизвестный часовой пояс не придумывается.

Конспект — подборка твоих цитат и комментариев по главам. Поддерживаются соседние папки .sdr у EPUB. Программа не передаёт заметки в облако. Личные конспекты можно открыть в Obsidian или любом редакторе Markdown.

Иностранные языки

Пункт 2 основного установщика или пункт 5 меню инструментов устанавливает FreeDict English-Russian и настройку русского языка перевода. После этого перезапусти KOReader.

Удерживай английское слово → словарный поиск. Он работает офлайн. Для перевода фразы выдели её и нажми «Перевести», для этого нужен интернет. Программа выбирает русский язык назначения один раз и затем сохраняет последующий выбор пользователя.

В словарном окне нажми Add to vocabulary builder. Для выборочного сбора отключи Auto add new words. Для сохранения примера включи Save context. В Vocabulary builder можно повторять слова прямо на Kindle.

Для выгрузки выйди из KOReader, подключи USB и выбери 4 в меню инструментов. В Documents/KOReader/Слова появятся HTML-карточки и файл «Слова для Anki.tsv». HTML открой браузером: щелчок по слову раскрывает ответ. TSV импортируй в Anki как текст с табуляцией, сопоставь поля «Слово», «Перевод», «Контекст», «Книга» и время. Для двусторонних карточек выбери подходящий тип записи в Anki. Пустой перевод означает отсутствие точного совпадения в словаре, а не ошибку экспорта.

Если в Anki используются стандартные типы только с двумя полями, сначала создай тип записи с нужными полями либо импортируй первые два, пропустив остальные.

Обновление, резервная копия и удаление

Установщик работает только с файлами своего расширения, дополнения заметок и выбранного словаря/настройки перевода. Книги, соседние .sdr, настройки чтения и внутреннюю сессию Яндекса он не переносит и не удаляет. Файлы входа pairing.txt не входят в устанавливаемый список.

Перед заменой изменённые файлы копируются на компьютер в Documents/KOReader/Резервные копии/Kindle-<дата-время>. Файл installation.json перечисляет изменённые пути и показывает, какие файлы существовали раньше. Если содержимое совпадает, оно пропускается. Повторное подключение аккаунта при обычной переустановке не требуется.

При ошибке записи установщик пытается вернуть исходные файлы. Если кабель физически отключён, завершить откат сразу может быть невозможно. Вновь подключи Kindle и скопируй файлы из резервной копии обратно в те же папки. Файлы, впервые добавленные незавершённой установкой, перечислены в installation.json как replaced: false. Их можно удалить вручную после проверки.

Для обновления выйди из KOReader, подключи Kindle и запусти установщик. Новому Kindle нужна собственная проверка совместимости; не копируй отчёт от другой читалки. В этот комплект входит прежний Yandex Books 0.6.0, поэтому уже совпадающие файлы не обновляются.

Для удаления Yandex Books убери только папку extensions/yandex-books-pw2 и дополнение koreader/plugins/yandexbooksnotes.koplugin. Книги и .sdr оставь, если нужны заметки. Сессию аккаунта можно отозвать через настройки Яндекс ID; удаление USB-папки не очищает внутреннее хранилище сессии.

Диагностическое расширение можно удалить отдельно — папка extensions/reading-kit-check. Для удаления дополнительного словаря убери koreader/data/dict/FreeDict English-Russian, для удаления патча — koreader/patches/2-reading-kit-russian.lua. Сам KOReader, другие словари и книги удалять не нужно.

Проверка на конкретном устройстве

1. Установщик находит правильный USB-диск. При нескольких устройствах позволяет выбрать.

2. KUAL показывает Reading Kit: check compatibility. После запуска появился report.json, установка читает его и сообщает результат.

3. Yandex Books запускается из KUAL, видны полка и кнопки, касания совпадают с элементами интерфейса.

4. Собственный аккаунт подключается, уже существующие загрузки и заметки сохранены.

5. Поиск по каталогу и полке выдаёт результаты при Wi-Fi.

6. Книга открывается в KOReader целиком, листается, шрифт меняется, оглавление и изображения показываются при наличии в EPUB.

7. Выделение и комментарий сохраняются после повторного открытия. Выход из KOReader возвращает в Yandex Books, если книга открыта из него.

8. Скачанная книга открывается при выключенном Wi-Fi.

9. Обычная веб-статья и RSS дают читаемые EPUB. Неподдерживаемая ссылка показывает ошибку.

10. Экспорт заметок содержит книгу, автора, цитату, комментарий, главу и время из исходных данных, а также время выгрузки с часовым поясом.

11. Словарь открывается без интернета. Перевод фразы при Wi-Fi использует русский язык.

12. Добавленное в Vocabulary builder слово появляется в HTML-карточках и TSV. Исходная база слов остаётся на Kindle.

13. Повторная установка не меняет книги, заметки и вход. Для заменённых файлов есть резервная копия.

14. При отсутствии Kindle или Python программа показывает понятное сообщение, окно не исчезает сразу.

Для диагностики подходят report.json и extensions/yandex-books-pw2/last-run.log. Не отправляй pairing.txt, адрес браузера после входа или сам токен.

Какие Kindle поддерживаются

Автоматическая проверка оценивает среду выполнения, а не выбирает устройство по названию USB-диска. Надпись Kindle или Paperwhite сама по себе не гарантирует совместимость.

Yandex Books

Нужны jailbreak, работающий KUAL с правами root, установленный KOReader, сенсорный экран и возможность запуска включённых 32-битных ARMv7-файлов. Экран — в книжной ориентации, шириной от 600 точек и высотой до 4096. Интерфейс масштабируется под разрешение.

Установщик сначала переносит небольшое диагностическое расширение. Его запуск на Kindle проверяет доступ к сенсору через системный интерфейс, FBInk и экран. Запускается программа, собранная тем же Go 1.23.12 и для той же ARMv7-среды, что приложение. Если эта программа не запускается, остаётся понятный отчёт об ошибке и основное приложение не устанавливается. Проверка не рисует интерфейс приложения и не перехватывает сенсор.

Модель и прошивка берутся из FBInk и системного файла прошивки, если они доступны. Серийный номер не записывается. Отчёт находится в extensions/reading-kit-check/report.json. Для другого устройства проверку нужно выполнить заново. Отчёт не является криптографическим доказательством и предназначен для обычной локальной установки.

Статьи, заметки и словари

Инструменты на компьютере работают с EPUB, соседними .sdr и базой Vocabulary Builder. Они привязаны к форматам KOReader, поэтому могут использоваться на разных Kindle с KOReader независимо от поддержки Yandex Books. Старые форматы метаданных и централизованное хранилище заметок могут потребовать доработки экспортёра. Сейчас экспорт заметок охватывает EPUB с соседней папкой .sdr.

Сам KOReader

Правильная сборка KOReader зависит от модели и прошивки. В официальной инструкции перечислены KindleHF для новых прошивок, PW2, Kindle и Legacy. Этот комплект не заменяет существующий KOReader и не скачивает его автоматически. Пользуйся официальной инструкцией установки и Kindle Modding. Обновлять прошивку ради установки этого комплекта не требуется.

Возможности Kindle Reading Suite 1.0.0

Установка

- Запуск с Mac и Windows с проверкой Python 3.9+, UTF-8 и русскими путями.

- Поиск USB-дисков по установленному KOReader, выбор при нескольких устройствах, ручной путь.

- Отдельная проверка на Kindle через KUAL: запуск ARMv7-программы, права root, FBInk, размеры экрана, наличие доступного сенсора, сведения о модели и прошивке при наличии.

- Установка Yandex Books после проверки среды. Резервная копия изменённых файлов на компьютере и попытка отката при ошибке записи. Повторная установка пропускает совпадающие файлы.

- Проверка SHA-256 файлов комплекта перед установкой и SHA-512 словаря.

- Подготовка локальных папок для ручного переноса по MTP, включая подключение аккаунта. Прямого автокопирования по MTP нет.

Ограничения

Не обещается поддержка всех моделей и прошивок Kindle. Комплект не делает jailbreak. Нативный клиент требует ARMv7 с рабочей 32-битной средой и сенсорного экрана. Не поддерживает кнопочное управление старых Kindle и Amazon Fire. Работа недокументированного API Яндекса зависит от сервиса. Windows и новые модели требуют отдельного практического тестирования.

Что остаётся проверить

Реальный компьютер Windows и подключённый Kindle в этой проверке недоступны. Поэтому статус «проверено на любой модели Kindle» или «подтверждено на Windows» этому выпуску не присваивается. PowerShell на macOS не заменяет Windows PowerShell 5.1, работу Проводника и cmd.exe.

На физическом Kindle нужно проверить запуск диагностики и приложения, реакцию на касания, открытие EPUB, возврат из KOReader и онлайн-перевод. Успешная проверка системных возможностей не подтверждает поведение всех моделей и прошивок. Реальный вход в Яндекс, доступ подписки и действующие недокументированные API в этом выпуске заново на устройстве не проверялись.

Самостоятельная проверка на компьютере

- Mac: открой Verify-Mac.command. Отчёт Mac-check.txt появится рядом с командой.

- Windows: открой Verify-Windows.cmd. Отчёт Windows-check.txt появится рядом с командой.

Эти команды проверяют комплект в временных папках и не устанавливают его на реальный Kindle. Если PowerShell недоступен, соответствующие 5 проверок отмечаются пропущенными, это видно в отчёте.

На конкретном Kindle выполни пункты из «Инструкции/Проверка после установки.md».
