# Обновление, резервная копия и удаление

Установщик работает только с файлами своего расширения, дополнения заметок и выбранного словаря/настройки перевода. Книги, соседние .sdr, настройки чтения и внутреннюю сессию Яндекса он не переносит и не удаляет. Файлы входа pairing.txt не входят в устанавливаемый список.

Перед заменой изменённые файлы копируются на компьютер в `Documents/KOReader/Резервные копии/Kindle-<дата-время>`. Файл installation.json перечисляет изменённые пути и показывает, какие файлы существовали раньше. Если содержимое совпадает, оно пропускается. Повторное подключение аккаунта при обычной переустановке не требуется.

При ошибке записи установщик пытается вернуть исходные файлы. Если кабель физически отключён, завершить откат сразу может быть невозможно. Вновь подключи Kindle и скопируй файлы из резервной копии обратно в те же папки. Файлы, впервые добавленные незавершённой установкой, перечислены в installation.json как `replaced: false`. Их можно удалить вручную после проверки.

Для обновления выйди из KOReader, подключи Kindle и запусти установщик. Новому Kindle нужна собственная проверка совместимости; не копируй отчёт от другой читалки. В этот комплект входит прежний Yandex Books 0.6.0, поэтому уже совпадающие файлы не обновляются.

Для удаления Yandex Books убери только папку `extensions/yandex-books-pw2` и дополнение `koreader/plugins/yandexbooksnotes.koplugin`. Книги и .sdr оставь, если нужны заметки. Сессию аккаунта можно отозвать через настройки Яндекс ID; удаление USB-папки не очищает внутреннее хранилище сессии.

Диагностическое расширение можно удалить отдельно — папка `extensions/reading-kit-check`. Для удаления дополнительного словаря убери `koreader/data/dict/FreeDict English-Russian`, для удаления патча — `koreader/patches/2-reading-kit-russian.lua`. Сам KOReader, другие словари и книги удалять не нужно.
