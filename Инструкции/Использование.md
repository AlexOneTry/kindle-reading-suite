# Как пользоваться

## Яндекс Книги

Открой KUAL → Yandex Books. Интернет нужен для обновления полки, поиска и первой загрузки книги. Книга должна быть доступна твоему аккаунту. Загруженный EPUB открывается в KOReader без интернета.

В KOReader удерживай слово или протяни выделение по тексту, затем выбери выделение или заметку. Шрифты, оглавление и изображения доступны через обычное меню KOReader. Если книга запущена из Yandex Books, выход из KOReader возвращает на полку. Позиции KOReader и встроенной читалки отдельные и не синхронизируются обратно в Яндекс.

При первом входе открывается официальный экран Яндекса. После входа возможна страница «Авторизация в приложении Букмейт не удалась». Скопируй полный адрес из адресной строки и вставь в окно программы. Ввод скрыт. Ошибка самой страницы не подтверждает вход: программа отдельно проверяет доступ к полке. Не передавай никому адрес с данными входа и файл pairing.txt. Не нужно вводить пароль Яндекса в программу или в чат.

Подробности и полный список возможностей версии 0.6.0 сохранены в папке Yandex-Books, файлы Инструкция.md и Функции.md.

## Статьи

Открой пункт 3 основного меню, затем 1. Вставь ссылку на статью. При подключённом USB-диске Kindle можно сохранить EPUB сразу на него. Иначе результат появится в папке пользователя `Documents/KOReader/Статьи`. На Kindle открой EPUB из папки «Статьи» через файловый менеджер KOReader.

Сохраняются текст, заголовки, ссылки и оглавление. Изображения не переносятся. Сайты с авторизацией, платным доступом, защитой или текстом, который появляется через JavaScript, могут не работать. Ссылки с логином/паролем в адресе отклоняются.

## RSS и Wallabag

В меню инструментов пункт 2 принимает RSS или Atom и сохраняет до пяти последних записей. Адрес можно запомнить. Повторное сохранение той же ссылки пропускается. Если сайт не открылся, используется доступный текст из самой ленты; иногда это только анонс.

Для загрузки лент прямо по Wi-Fi открой в KOReader Tools → News downloader и настрой адреса в его Settings. Нажми Download news. Плагин сохраняет HTML. Это отдельный встроенный инструмент KOReader: [инструкция](https://github.com/koreader/koreader/wiki/News-downloader).

Для Wallabag нужен свой сервер или аккаунт у поставщика сервиса. В плагине Wallabag на Kindle укажи адрес сервера, имя пользователя, пароль и данные своего API-клиента. Затем обнови список непрочитанных статей. Статьи скачиваются в EPUB. Чужой аккаунт, ключи или сервер в комплекте не предоставляются: [инструкция](https://github.com/koreader/koreader/wiki/Wallabag).

## Заметки и конспекты

1. Сделай выделения и комментарии в KOReader.
2. Выйди из KOReader, затем подключи USB.
3. В меню инструментов выбери 3. После экспорта программа покажет папку результата.

В `Documents/KOReader/Заметки/KOReader-<дата-время>` будут общий Markdown, структурированный JSON и папка «Конспекты» с отдельным файлом для каждой книги. В JSON сохраняются все доступные поля метаданных EPUB и документа KOReader, глава, страница, координаты выделения и время, если они есть в исходных данных. Время экспорта содержит часовой пояс компьютера. Время заметки сохраняется в том виде, в котором его записал Kindle: неизвестный часовой пояс не придумывается.

Конспект — подборка твоих цитат и комментариев по главам. Поддерживаются соседние папки .sdr у EPUB. Программа не передаёт заметки в облако. Личные конспекты можно открыть в Obsidian или любом редакторе Markdown.

## Иностранные языки

Пункт 2 основного установщика или пункт 5 меню инструментов устанавливает FreeDict English-Russian и настройку русского языка перевода. После этого перезапусти KOReader.

Удерживай английское слово → словарный поиск. Он работает офлайн. Для перевода фразы выдели её и нажми «Перевести», для этого нужен интернет. Программа выбирает русский язык назначения один раз и затем сохраняет последующий выбор пользователя.

В словарном окне нажми Add to vocabulary builder. Для выборочного сбора отключи Auto add new words. Для сохранения примера включи Save context. В Vocabulary builder можно повторять слова прямо на Kindle.

Для выгрузки выйди из KOReader, подключи USB и выбери 4 в меню инструментов. В `Documents/KOReader/Слова` появятся HTML-карточки и файл «Слова для Anki.tsv». HTML открой браузером: щелчок по слову раскрывает ответ. TSV импортируй в Anki как текст с табуляцией, сопоставь поля «Слово», «Перевод», «Контекст», «Книга» и время. Для двусторонних карточек выбери подходящий тип записи в Anki. Пустой перевод означает отсутствие точного совпадения в словаре, а не ошибку экспорта.

Если в Anki используются стандартные типы только с двумя полями, сначала создай тип записи с нужными полями либо импортируй первые два, пропустив остальные.
