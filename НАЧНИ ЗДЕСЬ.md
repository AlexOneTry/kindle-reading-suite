# Kindle Reading Suite 1.0.0

Комплект от 4 ноября 2026 года. Yandex Books 0.6.0 остаётся без изменений. Отдельные инструменты KOReader обновлены до 1.1.0. Установщик — 1.0.0.

## Что понадобится

- Электронная читалка Kindle с уже работающими jailbreak, KUAL и KOReader. Комплект не выполняет jailbreak, не меняет прошивку и не устанавливает KUAL или сам KOReader.
- Mac или Windows с Python 3.9 или новее. Никаких дополнительных Python-библиотек не требуется.
- USB-кабель с передачей данных. Для новых устройств с MTP есть отдельный порядок переноса.
- Собственный аккаунт и доступ к книгам Яндекса для работы с Yandex Books. Подписка в комплект не входит.

## Начало работы

1. Распакуй весь ZIP в обычную папку на компьютере. На Windows сначала нажми «Извлечь всё». Из окна архива запускать файлы нельзя.
2. Выйди из KOReader и подключи Kindle по USB.
3. На Mac открой **Install-Mac.command**, на Windows — **Install-Windows.cmd**.
4. Выбери **1**. Установщик сам ищет Kindle по установленному KOReader. Если устройств несколько, предложит выбрать одно. При необходимости можно указать путь к диску вручную.
5. Для нового устройства сначала скопируется только проверка совместимости. Извлеки Kindle, открой **KUAL → Reading Kit: check compatibility**, снова подключи Kindle и запусти установщик, пункт **1**.
6. Если проверка среды пройдена, установщик скопирует Yandex Books и дополнение для открытия заметок. После установки на компьютере выбери **4**, чтобы подключить свой аккаунт Яндекса. Ввод адреса после входа скрыт.
7. Извлеки Kindle, включи Wi-Fi и открой **KUAL → Yandex Books**.

Если приложение уже работает и обновление ему не нужно, для статей, заметок и слов используй пункт **3**. Пункт **2** устанавливает дополнительный словарь и настройку перевода отдельно.

Проверка среды не является проверкой каждой модели Kindle: касания, возврат из KOReader и открытие книг нужно проверить на конкретной читалке. При неподходящей платформе приложение не устанавливается. Подробности — **Инструкции/Совместимость.md**.

## Если двойной щелчок не запускает программу

**Mac.** Установи [Python для macOS](https://www.python.org/downloads/macos/). Открой Terminal, введи `/bin/bash ` с пробелом и перетащи `Install-Mac.command` в окно, нажми Enter. Для Python с python.org при ошибке сертификатов выполни поставляемую с ним `Install Certificates.command` из папки Python в Applications. Проверку HTTPS отключать не нужно.

**Windows.** Установи [Python для Windows](https://www.python.org/downloads/windows/). В установщике включи добавление Python в PATH и Python Launcher, если эти опции доступны. Открой комплект заново. Программа пробует `py -3`, затем `python`. Поддержка Windows зависит также от выбранного выпуска Python; Windows 10/11 — основной целевой вариант. Реальный запуск на Windows в этой сборке ещё не подтверждён.

## Где остальные инструкции

- **Инструкции/Использование.md** — книги, статьи, RSS, Wallabag, заметки, словари и Anki.
- **Инструкции/Совместимость.md** — автоматическая проверка, старые и новые Kindle.
- **Инструкции/MTP.md** — устройства, которые не появляются обычным USB-диском.
- **Инструкции/Обновление и восстановление.md** — резервные копии, обновление и удаление.
- **Инструкции/Проверка после установки.md** — короткий список проверки на читалке.
- **FUNCTIONS.md** — полный список возможностей, **CHANGELOG.md** — что добавлено.
- **TEST-REPORT.md** — что действительно проверено и что требует устройства или Windows.

Личные книги, заметки, слова, пароли и токены в этот архив не включены. Комплект не является официальным продуктом Amazon, Яндекса или KOReader.
