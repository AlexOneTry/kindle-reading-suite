# Что нового в 1.1.0 · 4 ноября 2026

- В командах Mac и Windows проверяется наличие Python 3.9 или новее.
- На Windows добавлен запуск через `python`, если команда `py -3` недоступна.
- Вывод принудительно использует UTF-8, в том числе для русских путей и текстов.
- Поиск USB-дисков пропускает недоступные диски. Появился номер версии `--version`.
- В комплекте Suite добавлены автоматический поиск Kindle, проверка среды через KUAL и установка с резервной копией.
