# Функции набора для KOReader

- Сохранение веб-статьи в EPUB с заголовками, оглавлением и ссылкой на оригинал.
- Загрузка нескольких записей RSS/Atom, список сохранённых лент, сохранение на компьютер или на Kindle по USB.
- Локальная выгрузка выделений и заметок из .sdr в JSON, общий Markdown и отдельные конспекты по книгам и главам.
- Англо-русский StarDict FreeDict + WikDict и настройка русского языка как цели перевода в KOReader.
- Выгрузка Vocabulary Builder в офлайн-карточки HTML и TSV для Anki, с контекстом и словарным переводом при наличии совпадения.
- Запуск с Mac и Windows через локальное меню или командную строку.
