# Набор для чтения в KOReader · 1.1.0

Отдельная утилита для Mac и Windows. Открой **KOReader Tools.command** на Mac или **KOReader-Tools-Windows.cmd** на Windows. Нужен Python 3.9 или новее. На Mac можно также набрать в Terminal `python3 `, перетащить `reading.py` в окно и нажать Enter. Yandex Books в KUAL не участвует в этих сценариях.

## Статьи и RSS

- **1** сохраняет открытую веб-статью в EPUB. Вставь ссылку и выбери, сохранять на компьютере или прямо на подключённый Kindle. EPUB содержит текст, заголовки, ссылки и оглавление. Иллюстрации пока не переносятся. Сайты с авторизацией, защитой или текстом, который появляется только после загрузки JavaScript, могут не открыться.
- **2** скачивает до пяти последних записей RSS/Atom в отдельные EPUB. Ленту можно запомнить в меню. Если страница недоступна, а лента содержит текст, используется текст из ленты, который может быть короче статьи.
- Чтобы скачивать RSS прямо по Wi-Fi на Kindle, открой **Инструменты → News downloader** в KOReader, добавь ссылку на свою ленту в настройках и нажми **Download news**. Встроенный плагин сохраняет HTML. [Руководство News downloader](https://github.com/koreader/koreader/wiki/News-downloader)
- Если у тебя уже есть сервер Wallabag, плагин **Wallabag** умеет скачивать непрочитанные статьи в EPUB. В настройках на Kindle укажи сервер, папку скачивания и реквизиты своего API-клиента. [Руководство Wallabag](https://github.com/koreader/koreader/wiki/Wallabag)

## Конспекты

Сделай выделение и при желании добавь комментарий в KOReader. Выйди из KOReader и подключи Kindle по USB. Выбери **3** в утилите. В `Документы/KOReader/Заметки` появятся общий Markdown, структурированный JSON и отдельный конспект на книгу, сгруппированный по главам. JSON содержит доступные метаданные EPUB и время выгрузки с часовым поясом. Для заметок сохраняется время, записанное самой читалкой. Экспортёр ищет соседние .sdr на USB-диске.

## Английский → русский и слова

1. В KOReader удерживай слово, чтобы открыть офлайн-словарь. Если англо-русского словаря ещё нет, пункт **5** устанавливает входящий в архив **FreeDict + WikDict** и выбирает русский для перевода фраз при следующем запуске KOReader. Существующие словари сохраняются.
2. Для фразы выдели текст и выбери **«Перевести»**. Это онлайн-действие KOReader, для него нужен интернет. Словарный поиск отдельных слов работает офлайн.
3. В окне словаря нажми **Add to vocabulary builder** («Добавить в словарь для запоминания»). В **Vocabulary builder** можно повторять слова на Kindle. Если предпочитаешь добавлять выборочно, выключи **Auto add new words**. Опция **Save context** сохраняет соседний текст, если он доступен.
4. Выйди из KOReader, подключи Kindle и выбери **4** в утилите. В `Документы/KOReader/Слова` появятся HTML-карточки и TSV для Anki. В перевод подставляются точные совпадения из FreeDict. Для остальных слов остаётся контекст и пустое поле перевода, которое можно заполнить самому.

[Руководство KOReader](https://koreader.rocks/user_guide/) · [FreeDict и условия лицензии](https://freedict.org/downloads/)

## Команды для запуска из терминала

```sh
python3 reading.py article "https://example.org/article"
python3 reading.py feed "https://example.org/rss.xml" --limit 5
python3 reading.py notes "/Volumes/Kindle"
python3 reading.py words "/Volumes/Kindle"
python3 reading.py install "/Volumes/Kindle" --translation
```

На Windows замени `python3` на `py -3`, а `/Volumes/Kindle` на букву диска, например `E:\`.
