# Функции Yandex Books для Kindle

- Вход в свой аккаунт Яндекса через USB с Mac или Windows. Проверка доступа к полке при подключении.
- «Моя полка» Яндекса, её локальная копия, имя аккаунта и статус подключения.
- Вкладки «Полка», «Каталог», «Хочу прочитать» и «Загрузки».
- Поиск по названию и автору на полке, сортировка по названию или времени чтения, списки непрочитанных и скачанных.
- Поиск текстовых книг и сериалов по каталогу Яндекс Книг, история запросов, страницы результатов и фильтр подтверждённой доступности.
- Карточка книги по кнопке с тремя точками с обложкой и аннотацией при наличии данных, автором и сведениями о серии.
- Книги автора, список известных томов серии и переход к следующему известному тому при наличии номеров.
- Добавление в «Мои книги» Яндекса после подтверждения.
- Локальный список «Хочу прочитать» и очередь скачивания нескольких книг.
- Чтение одним нажатием через KOReader, «Продолжить чтение» и простая встроенная читалка через меню книги.
- Возврат из KOReader после команды «Выйти» на полку или к исходной странице каталога.
- Чтение скачанных EPUB офлайн, проверка EPUB, прогресс загрузки, отмена и повтор.
- Читаемые имена EPUB, сохранение папок .sdr, показ размера файла и освобождение места с сохранением .sdr.
- Показ числа выделений и заметок из соседней .sdr и переход в закладки книги через дополнение Yandex Books Notes для KOReader.
- Шрифты, оглавление, изображения из EPUB, выделения и заметки средствами KOReader.
- Просмотр серверного процента чтения, когда его присылает Яндекс. Точная позиция KOReader хранится локально.
- Отдельный экспортёр заметок в Markdown и JSON доступен отдельным архивом.
