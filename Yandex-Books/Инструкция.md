# Яндекс Книги для Kindle Paperwhite · 0.6.0

Самостоятельное приложение для Kindle Paperwhite с джейлбрейком и KUAL. Интерфейс подстраивается под размер экрана в книжной ориентации. Сборка рассчитана в том числе на Paperwhite 5 (11-е поколение, 1236 × 1648).

## Установка и первый вход

1. Выйди из KOReader и подключи Kindle к компьютеру по USB.
2. Распакуй установочный архив. Скопируй папку `yandex-books-pw2` из его папки `extensions` в папку `extensions` на Kindle.
3. На Windows открой **Connect-Kindle-Windows.cmd** из распакованного архива. На Mac открой **Подключить Kindle.command**. Команда откроет официальный экран входа Яндекса. После входа браузер может показать «Авторизация в приложении Букмейт не удалась», потому что страница пытается открыть мобильное приложение. Скопируй полный адрес этой страницы (на Windows Ctrl+L, затем Ctrl+C, на Mac ⌘L, затем ⌘C). Вставь его в окно команды и нажми Enter. Ввод скрыт. Если macOS блокирует двойной щелчок, запусти команду в Terminal: введи `/bin/bash `, перетащи файл команды в окно и нажми Enter.
4. Извлеки Kindle, подключи его к Wi-Fi и открой **KUAL → Yandex Books**. Приложение перенесёт токен во внутреннее хранилище Kindle и удалит файл передачи с USB-раздела.
5. Выбери текстовую книгу со своей полки. Кнопка **Читать в KOReader** откроет исходный EPUB в установленном KOReader. Кнопка **Читать в Yandex Books** откроет простую встроенную читалку. Нажимай на левую или правую треть страницы, чтобы листать. **Полка** возвращает к списку. **Выход** закрывает приложение. Позиция сохраняется локально после перелистывания.

Для проверки подойдёт текстовая книга, уже добавленная в «Мои книги» и доступная по твоей подписке. Компьютер нужен для первого входа и повторного подключения после истечения токена. Во время чтения Kindle подключается к сервису по Wi‑Fi самостоятельно. Встроенная читалка показывает только текст и сохраняет свою позицию отдельно. Интернет нужен для обновления полки и первой загрузки книги. Сохранённые EPUB открываются в KOReader без интернета.

## Обновление до 0.6.0

Если приложение уже установлено, выйди из KOReader и подключи Kindle. В папке `extensions/yandex-books-pw2` замени из нового архива файлы `yandex-books`, `start.sh` и `config.xml`, а также папку `licenses`. Повторный вход не нужен.

Приложение добавляет недостающий признак EPUB к книгам из Яндекса, включая ранее сохранённые файлы. Путь книги и её папка с заметками сохраняются.

В KOReader доступны выделения, заметки, шрифты, оглавление и иллюстрации из EPUB. Файлы лежат в папке `Yandex Books` в корне USB-диска. Для каждой книги используется постоянный путь. При повторном открытии KOReader сможет восстановить её позицию и заметки. Открытые ранее EPUB можно найти и напрямую в файловом менеджере KOReader. Позиции встроенной читалки и KOReader хранятся отдельно. Заметки и прогресс KOReader остаются локально.

Дополнение **Yandex Books Notes** нужно для перехода прямо к закладкам. Скопируй из архива папку `koreader/plugins/yandexbooksnotes.koplugin` в `koreader/plugins` на Kindle.

Полный список возможностей находится в **Функции.md**, изменения этого выпуска — в **Что нового.md**. Файлы входят в архив.

## Каталог и возврат из KOReader

- Нажми **Каталог** вверху полки, введи название или автора и нажми **Найти**. Поиск работает по каталогу сервиса при включённом Wi-Fi. Результаты включают текстовые книги и сериалы. Нажми на книгу, чтобы открыть её в KOReader при наличии доступа по подписке.
- Книга из каталога появляется на локальной полке после открытия. Поиск и чтение не меняют библиотеку в аккаунте Яндекса.
- Если книга была открыта из Yandex Books, выбери в верхнем меню KOReader **Выйти**. После закрытия KOReader приложение снова откроет твою полку.

## Работа с полкой

- Нажми название книги для открытия в KOReader. Кнопка с тремя точками справа сразу открывает карточку книги. В карточке нажми «Файл и чтение», чтобы открыть встроенную читалку, узнать размер загрузки или удалить EPUB с отдельным подтверждением. Папка заметок .sdr остаётся на диске.
- «Продолжить чтение» открывает последнюю книгу, выбранную в приложении. KOReader сам восстанавливает позицию.
- «Поиск» ищет по названию и автору. На полке правая кнопка открывает список вариантов сортировки и фильтров. «Хочу прочитать» и «Загрузки» доступны из верхних вкладок. В «Загрузках» кнопка «К очереди» открывает список ожидающих скачивания.
- Один раз открой полку с Wi-Fi. После этого её копия и скачанные книги доступны офлайн. Кнопка «Обновить» запрашивает данные Яндекса и показывает, если нужно переподключить аккаунт.
- Новые EPUB получают читаемое имя. Старый файл переименовывается вместе с соседней .sdr при открытии. Если рядом нет .sdr, сохраняется старый путь для совместимости с централизованным хранилищем KOReader.
- Прогресс из Яндекса отображается в меню книги, если сервер его прислал. Точная позиция KOReader остаётся локальной. Запись позиции в Яндекс не реализована.
- Экспорт Markdown и JSON находится в отдельном архиве KOReader Notes Export.

## Если что-то не получилось

- **Нет пункта в KUAL.** Проверь, что на Kindle есть `extensions/yandex-books-pw2/config.xml` и `menu.json`. Закрой и снова открой KUAL.
- **Нет доступа к полке.** Проверь Wi‑Fi и дату Kindle. Если приложение сообщает об истёкшем или отклонённом входе, повтори подключение через USB.
- **Приложение вернулось на главный экран.** Посмотри файл `extensions/yandex-books-pw2/last-run.log` на Kindle. Этот журнал можно передать для диагностики. Файл `pairing.txt` содержит данные входа, его передавать не нужно.
- **Выход с экрана.** Нажми «Выход» в правом верхнем углу. Короткое нажатие аппаратной кнопки питания также предусмотрено для выхода, если приложение смогло получить доступ к этой кнопке.

Для удаления убери `extensions/yandex-books-pw2` с USB-раздела. Во внутренней папке `/var/local/yandex-books-pw2` хранятся сессия и позиции чтения. Доступ к сессии можно отозвать в настройках Яндекс ID.

## Совместимость и исходники

На Mac проверены запросы на тестовом сервере, чтение EPUB и отрисовка. Приложение собрано для Linux ARMv7 soft-float. Основной сценарий чтения подтверждён на Paperwhite 5. Новые возможности версии 0.6.0 ещё нужно проверить на читалке. Клиент использует внутренний API сервиса по опубликованному описанию [Yandex Books Desktop](https://github.com/Gorbachevvv/yandex-books-desktop). Доступ через этот интерфейс может измениться.

Сборка приложения из каталога исходников с Go 1.23.12:

```sh
go test ./...
GOOS=linux GOARCH=arm GOARM=7,softfloat CGO_ENABLED=0 go build -trimpath -ldflags="-s -w" -o yandex-books .
```

FBInk для ARM EABI извлечён из официального релиза [KindleModding Hotfix 2.5.0](https://github.com/KindleModding/Hotfix/releases/tag/2.5.0). Установочный архив содержит только исполняемый файл FBInk из этого релиза, который рисует страницы. Информация об исходниках и лицензиях лежит рядом с ним в `THIRD-PARTY.txt`.
